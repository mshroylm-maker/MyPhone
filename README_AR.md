# مشروع MyPhone — النسخة التأسيسية

هذه نسخة أولية لواجهة Android فقط. لا تحتوي بعد على اتصال شبكي أو تحكم عن بعد أو قراءة للرسائل/المكالمات/الملفات.

## بناء APK من الهاتف فقط باستخدام GitHub

1. افتح https://github.com من متصفح الهاتف وأنشئ حساباً أو سجّل الدخول.
2. أنشئ مستودعاً جديداً باسم `MyPhone` واجعله Private.
3. ارفع محتويات هذا المجلد إلى المستودع مع الحفاظ على المسارات.
4. افتح تبويب Actions داخل المستودع.
5. اختر `Build MyPhone APK` ثم `Run workflow` إذا لم يبدأ البناء تلقائياً.
6. بعد نجاح البناء افتح نتيجة التشغيل (Run).
7. انزل إلى Artifacts واضغط `MyPhone-debug-apk` لتنزيل ملف APK.
8. فك ضغط الملف، ثم ثبّت `app-debug.apk` على هاتفك بعد السماح بالتثبيت من هذا المصدر.

## ملاحظات مهمة

- هذا المشروع لا يعمل كأداة تجسس ولا يتجاوز موافقات Android.
- مشاركة الشاشة تتطلب موافقة نظام Android عند بدء الجلسة.
- صلاحيات SMS وسجل المكالمات مقيدة في Android وقد تتطلب أن يكون التطبيق تطبيق الرسائل/الهاتف الافتراضي أو استخدام واجهات رسمية.
- لا تضع كلمات المرور أو مفاتيح الاتصال داخل المستودع.
- لا تنشر APK للآخرين قبل إضافة المصادقة والتشفير واختبار الأمان.
